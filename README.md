# Telegram-бот отчётов для участников ЗБТ

Участники закрытого бета-тестирования сообщают о багах и проблемах и предлагают идеи по улучшению. Администраторы разбирают отчёты в отдельной группе Telegram, а участник следит за статусом в личных сообщениях.

## Возможности

- Три типа отчётов: 🐞 баг, ⚠️ проблема, 💡 идея
- Анкета из трёх шагов: ник, подробное описание, доказательства (скриншоты, видео, файлы, голосовые, ссылки, до 10 вложений)
- Для багов и проблем доказательства обязательны, для идей нет
- Ник запоминается, и в следующий раз его можно выбрать одной кнопкой
- Доступ только участникам ЗБТ: бот проверяет, состоит ли человек в конференции ЗБТ
- Номер у каждого отчёта, раздел «Мои отчёты» со статусами
- Карточка отчёта в группе администраторов с кнопками, вложения копируются туда же
- Статусы: 🟡 Новый, 🔵 В работе, 🟢 Решено, 🔴 Отклонено, участник получает уведомление о каждом изменении
- Ответ администратора участнику: ответом (reply) на карточку отчёта или командой `/answer`
- Защита от спама: пауза между отчётами и суточный лимит, блокировка нарушителей командой `/ban`

## Как это работает

1. Участник нажимает «Сообщить о баге», «Сообщить о проблеме» или «Предложить идею».
2. Указывает ник, описывает ситуацию, прикладывает доказательства и проверяет отчёт.
3. В группе администраторов появляется карточка с кнопками и вложениями.
4. Администратор берёт отчёт в работу, решает или отклоняет его, участник получает уведомление.

## Команды администраторов (только в группе администраторов)

| Команда | Что делает |
|---|---|
| `/list` | открытые отчёты (новые и в работе) |
| `/report номер` | показать отчёт с кнопками |
| `/find текст` | поиск по нику, @username, ID и описанию |
| `/progress номер` | взять в работу |
| `/done номер [комментарий]` | решено или учтено |
| `/reject номер [причина]` | отклонить, причину увидит участник |
| `/reopen номер` | вернуть в работу |
| `/answer номер текст` | написать участнику |
| ответ (reply) на карточку | текст уходит участнику |
| `/ban ID`, `/unban ID` | заблокировать или разблокировать отправку отчётов |
| `/stats` | статистика по статусам и типам |
| `/close`, `/open` | приостановить или возобновить приём |
| `/export` | выгрузка всех отчётов в CSV |
| `/adminhelp` | список команд |

`/chatid` работает в любом чате и показывает ID группы и темы.

## Настройка

Переменные задаются в панели хостинга (вкладка Environment). Токен в репозиторий не добавляйте.

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_CHAT_ID` | ID группы администраторов, число с минусом (обязательно) |
| `ADMIN_THREAD_ID` | ID темы, если в группе включены Темы (необязательно) |
| `ADMIN_IDS` | Telegram ID администраторов через запятую; если задано, статусы меняют только они (необязательно) |
| `BETA_CHAT_ID` | ID конференции ЗБТ: пользоваться ботом смогут только её участники. Без него бот открыт для всех |
| `ALLOWED_IDS` | Telegram ID, которым доступ разрешён всегда (необязательно) |
| `PROJECT_NAME` | название проекта |
| `BANNER_PATH` | картинка над меню, по умолчанию `banner.jpg` |
| `TZ_OFFSET_HOURS` | часовой пояс для дат, по умолчанию 2 |
| `MAX_REPORTS_PER_DAY` | сколько отчётов в сутки может отправить один участник, по умолчанию 10 |
| `COOLDOWN_SECONDS` | пауза между отчётами одного участника, по умолчанию 60 |

Чтобы проверка участников работала, добавьте этого бота в конференцию ЗБТ администратором (достаточно любых прав): без этого Telegram не отдаёт список участников.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Данные и безопасность

- Бот хранит Telegram ID, имя, username, ник и текст отчёта в файле `feedback.db`. Периодически делайте `/export`.
- Вложения бот не хранит: при отправке отчёта он копирует их в группу администраторов, поэтому сообщения участника с вложениями не нужно удалять до отправки.
- Если вы задали `ADMIN_IDS`, анонимные администраторы группы (отправка от имени группы) статусы менять не смогут.
- Если токен бота попал в открытый доступ, перевыпустите его в @BotFather (`/revoke`).
