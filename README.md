# Telegram-бот отчётов для ОБТ

Бот открытого бета-тестирования: любой желающий сообщает о багах и проблемах и предлагает идеи по улучшению. Отчёты приходят в тему «ОБТ ОТЧЕТЫ» в группе администраторов, а автор следит за статусом в личных сообщениях.

## Возможности

- Три типа отчётов: 🐞 баг, ⚠️ проблема, 💡 идея
- Анкета из трёх шагов: ник, подробное описание, доказательства (скриншоты, видео, файлы, голосовые, ссылки, до 10 вложений)
- Для багов и проблем доказательства обязательны, для идей нет
- Ник запоминается, и в следующий раз его можно выбрать одной кнопкой
- Доступ открыт всем: бот не проверяет членство в группах
- Номер у каждого отчёта, раздел «Мои отчёты» со статусами
- Карточка отчёта в теме «ОБТ ОТЧЕТЫ» с кнопками, вложения копируются туда же
- Статусы: 🟡 Новый, 🔵 В работе, 🟢 Решено, 🔴 Отклонено, автор получает уведомление о каждом изменении
- Ответ администратора автору: ответом (reply) на карточку отчёта или командой `/answer`
- Защита от спама, так как бот открыт всем: пауза между отчётами, суточный лимит, блокировка нарушителей командой `/ban`

## Как это работает

1. Пользователь нажимает «Сообщить о баге», «Сообщить о проблеме» или «Предложить идею».
2. Указывает ник, описывает ситуацию, прикладывает доказательства и проверяет отчёт.
3. В теме «ОБТ ОТЧЕТЫ» появляется карточка с кнопками и вложениями.
4. Администратор берёт отчёт в работу, решает или отклоняет его, автор получает уведомление.

## Команды администраторов (в группе администраторов)

| Команда | Что делает |
|---|---|
| `/list` | открытые отчёты (новые и в работе) |
| `/report номер` | показать отчёт с кнопками |
| `/find текст` | поиск по нику, @username, ID и описанию |
| `/progress номер` | взять в работу |
| `/done номер [комментарий]` | решено или учтено |
| `/reject номер [причина]` | отклонить, причину увидит автор |
| `/reopen номер` | вернуть в работу |
| `/answer номер текст` | написать автору |
| ответ (reply) на карточку | текст уходит автору |
| `/ban ID`, `/unban ID` | заблокировать или разблокировать отправку отчётов |
| `/stats` | статистика по статусам и типам |
| `/close`, `/open` | приостановить или возобновить приём |
| `/export` | выгрузка всех отчётов в CSV |
| `/adminhelp` | список команд |

`/chatid` работает в любом чате и показывает ID группы и темы.

## Настройка

Переменные задаются в панели хостинга (вкладка Environment). Токен в репозиторий не добавляйте.

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_CHAT_ID` | ID группы администраторов, число с минусом (обязательно) |
| `ADMIN_THREAD_ID` | ID темы «ОБТ ОТЧЕТЫ»: напишите `/chatid` внутри этой темы. Без него отчёты придут в общий чат группы |
| `ADMIN_IDS` | Telegram ID администраторов через запятую; если задано, статусы меняют только они (необязательно) |
| `PROJECT_NAME` | название проекта |
| `BANNER_PATH` | картинка над меню, по умолчанию `banner.jpg` |
| `TZ_OFFSET_HOURS` | часовой пояс для дат, по умолчанию 2 |
| `MAX_REPORTS_PER_DAY` | сколько отчётов в сутки может отправить один человек, по умолчанию 10 |
| `COOLDOWN_SECONDS` | пауза между отчётами одного человека, по умолчанию 60 |

Бот должен быть администратором группы администраторов, чтобы публиковать карточки и вложения в теме.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Данные и безопасность

- Бот хранит Telegram ID, имя, username, ник и текст отчёта в файле `feedback.db`. Периодически делайте `/export`.
- Вложения бот не хранит: при отправке отчёта он копирует их в группу администраторов, поэтому автору не нужно удалять свои сообщения до отправки.
- Бот открыт всем, поэтому следите за спамом: уменьшите `MAX_REPORTS_PER_DAY` или `COOLDOWN_SECONDS` при необходимости, а нарушителей блокируйте через `/ban`.
- Если вы задали `ADMIN_IDS`, анонимные администраторы группы (отправка от имени группы) статусы менять не смогут.
- Если токен бота попал в открытый доступ, перевыпустите его в @BotFather (`/revoke`).
